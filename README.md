# DevOps Lab Guides (CS4203T-D)

Two guides for the DevOps laboratory practicals 1–13, built around one small Flask app.

| File | What it is |
| --- | --- |
| [Practicals-Execution-Guide.md](Practicals-Execution-Guide.md) | Copy-paste commands and files to run every practical (WSL Ubuntu + Docker Desktop), with expected output and troubleshooting |
| [DevOps-Theory-Commands-Viva-Guide.md](DevOps-Theory-Commands-Viva-Guide.md) | Theory, major commands explained, and viva answers for each practical |

## Practicals covered

1. DevOps lifecycle and tools
2. & 3. Git and GitHub — configure, branch, merge, pull request
4. Jenkins — automated build and test
5. GitHub Actions — CI/CD pipeline
6. & 7. Docker — basic commands, Dockerfile and images
8. Docker Compose — Flask + Redis
9. & 10. Kubernetes (kind) — Pods, Deployments, Services, ConfigMap, scaling, rolling update, rollback
11. Terraform — infrastructure as code (Docker provider)
12. Ansible — configuration management and idempotency
13. Prometheus and Grafana — monitoring
